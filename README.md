# Pierre-Olivier Bolduc

Robotics engineer (M.Sc., Université Laval) interested in robotics, mechanics, mathematical modeling, and computational engineering.

## Selected Projects

- **[The Topology of Slicing](https://github.com/pobol2/Topology-of-Slicing)**: A mathematical framework for additive manufacturing slicers, exploring volumetric Hilbert paths and robot-aware motion planning.

- **[Shift, Then Turn](https://github.com/pobol2/Shift-Then-Turn)**: Closed-form robotic in-grasp manipulation using passive contacts, validated through physical experiments and MuJoCo simulations.

- **[Physics Engine](https://github.com/pobol2/Physics-Engine)**: A C++ library for simulating classical mechanical systems, with numerical integration, constraints, and verification tools.

- **[Landau–Lifshitz Mechanics Solutions](https://github.com/pobol2/Mechanics-Landau-Solution)**: An illustrated [online solution manual](https://pobol2.github.io/Mechanics-Landau-Solution/) built using a reusable [LaTeX framework](https://github.com/pobol2/Solution-Manual-Template).

- **[PCMode](https://github.com/pobol2/PCMode)**: A Windows application for managing displays, audio, lighting, applications, and connected devices through configurable environments.
